# 预处理修正后的成对重训练验证

## 本轮结论

本轮实际重新训练了4种数据处理×3个固定随机种子，每次200轮；不是仅修改文件或运行语法检查。

网络、预训练CNN冻结、损失、原配置学习率1e-5、batch64、T=1、RMSprop、随机种子和划分在组间固定。所有组均使用恒定学习率，无旋转输出缩放、CNN微调或梯度裁剪。

## 检查与证据

- 每个相同种子在四组中的初始网络权重哈希完全一致。
- 同一组的模型仅按验证损失选轮次，测试结果没有用于调学习率或选择种子。
- 12次训练完整保存200轮train/val日志、预测和导出轨迹；全部固定种子均保存checkpoint。
- 保存重载输出对照、原始图像输入与缓存特征路径对照、从导出TUM独立重算ATE均通过。
- 本轮模型源码哈希保持不变。

## 结果适用范围

这是旧单序列上已接触测试段的预处理纠错检查，不是新的独立测试成绩。
投影仍保持上一轮自选参数，以隔离两项修正的影响；因此即使结果改善，也不能宣称已完成原论文baseline复现。
本轮与此前pilot表格的batch和调度不同；因而因果比较应使用本轮A_old与D_both_corrected，不跨轮直接归因。
